# 🌱 Enterprise ESG Supply Chain Risk & Compliance Dashboard

An interactive capstone project developed for the Bachelor of Business Administration (BBA) program at the Indian Institute of Technology (IIT) Patna. This decision-support tool helps corporate procurement and supply chain teams analyze vendor sustainability and regulatory compliance.

## 🚀 Project Overview
Modern enterprises face increasing pressure to monitor Scope 3 carbon emissions, fair-labor practices, and environmental regulations. This application automates the collection, weighting, and risk-tier categorization of tier-1 suppliers based on multi-pillar ESG metrics.

## 🛠️ Tech Stack & Architecture
* **Language:** Python 
* **Data Processing & Analytics:** Pandas
* **User Interface & Web App:** Streamlit
* **Deployment Architecture:** Local execution / Streamlit Community Cloud ready

## 📊 Core Features
* **Live Data Editor:** Interactive grid allowing users to modify existing supplier metrics or dynamically add new vendors.
* **Automated Weighted Scoring:** Automatically computes normalized (0–100 scale) sub-scores for:
  * *Environmental Impact* (Carbon Footprint & Waste Management)
  * *Social & Governance Compliance* (Labor Wages & Governance Practices)
* **Dynamic Risk Categorization:** Instantly flags suppliers into actionable tiers:
  * 🟢 Low Risk (Preferred Supplier)
  * 🟡 Medium Risk (Audit Needed)
  * 🔴 High Risk (Action Required)
* **Interactive Filtering & Visuals:** Filter data by geographic location and view real-time risk distribution charts.
